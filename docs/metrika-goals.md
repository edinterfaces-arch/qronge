# Цели Метрики 113405844

После деплоя: Цели → Добавить цель → Клик по кнопке → https://qronge-sale.ru/ → Перейти и выбрать кнопку. В режиме «Взаимодействие с сайтом» разрешите аналитику и откройте форму; затем вернитесь к выбору элемента. Используйте конечный адрес страницы без редиректа /opt/.

Стабильные ID: `request-m5` (аналогично slug других моделей), `request-product` (страница товара), `request-mobile`, `lead-submit`, `phone-header`, `phone-footer`, `phone-mobile`, `phone-store`, `store-directions`.

Для объединения кнопок по действию можно вместо визуальной цели создать цель «Целевое событие» с соответствующим идентификатором:

| Идентификатор | Действие |
| --- | --- |
| `lead_open` | Открытие формы предложения |
| `lead_submit_click` | Клик по кнопке отправки, включая невалидную форму |
| `lead_success` | Сервер подтвердил сохранение заявки |
| `phone_click` | Клик по размеченным телефонным ссылкам |
| `directions_click` | Открытие маршрута в Яндекс Картах |

Главная конверсия заявки — `lead_success`: клик по отправке не подтверждает получение заявки. Цели нужно сохранить в кабинете Метрики; код сайта не создаёт их автоматически. Аналитика работает после согласия посетителя. Не суммируйте одинаковые действия из визуальных и событийных целей как разные заявки.

Публичные страницы разрешают встраивание только HTTPS-доменам интерфейса Метрики из официальной документации. Админка, API и служебные ответы сохраняют запрет на встраивание. Прокси Timeweb не должен добавлять свой X-Frame-Options: DENY поверх ответа приложения.
