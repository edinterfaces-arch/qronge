# MOKWHEEL: магазин, оптовый каталог, блог, документы

## Страницы

- `/` — магазин MOKWHEEL, бренды MOKWHEEL / QRONGE / PUCKIPUPPY, фотографии владельца, телефоны, адрес и Яндекс Карта.
- `/opt/` — оптовые электровелосипеды. Короткое вступление, далее сразу ассортимент; цена единицы и минимальной партии.
- `/elektrosamokaty/`, `/elektromototsikly/` — категории оптового каталога.
- `/blog/` — 12 оригинальных коротких практических статей для оптовых покупателей.
- `/blog/<slug>/` — серверная страница статьи: заголовок, описание, canonical, Open Graph, BlogPosting, содержание и связанные статьи.
- `/legal/` — ссылки на действующие страницы и документы, которые готовятся к публикации.
- `/legal/sales-agreement/`, `/legal/warranty/`, `/legal/company-details/` — честно обозначенные страницы ожидания документов. Без выдуманных юридических условий, закрыты от индексации.

Старый маршрут `/elektrovelosipedy/` перенаправляется с кодом 301 в `/opt/`. URL товаров сохранены. Все статьи включены в sitemap.

## Фотографии и адрес

Пять оригинальных JPEG-файлов предоставлены владельцем 4 октября 2026 года. Они используются без изменения исходных файлов; кадрирование выполняет CSS. Фото магазина не служит обещанием наличия конкретной модели.

Владелец подтвердил адрес: **ТК «Южные ворота», выход 5, линия Ж8, павильоны 122–128**. Это значение имеет приоритет над первоначальным упоминанием «Садовода». Карта показывает торговый комплекс; павильоны описаны текстом рядом. Не добавлены неподтверждённые часы работы или статус официального дилера.

Яндекс Карты: https://yandex.ru/maps/org/yuzhnyye_vorota/1170329985/
Инструкция по виджету: https://yandex.ru/support/maps/ru/concept/get-map-reference

## SEO

Темы отвечают разным задачам: выбор курьерского велосипеда, маршрут доставки, закупка оптом, размер парка, аренда, батарея, обслуживание, груз, бюджет, приёмка, отправка ТК и сравнение серии M.

Частотность запросов не измерялась. Статьи не обещают позиции в поиске. Использованы оригинальные материалы, реальные фото, внутренняя перелинковка и отдельные URL. Визуальное направление блога — лента публикаций и спокойная читаемая колонка по референсу Дзена; интерфейс и тексты созданы для MOKWHEEL.

Оригинальный контент: https://webmaster.yandex.ru/blog/yandeks-obnovil-algoritmy-poiska-chtoby-luchshe-opredelyat-neoriginalnyy-kontent

При подключении собственного домена нужно изменить PUBLIC_ORIGIN в Timeweb, чтобы canonical и sitemap использовали его. Без этой переменной production использует существующий адрес приложения Timeweb.

## Развёртывание

Dockerfile копирует articles.mjs и pages.mjs вместе с сервером. Карта разрешена в CSP только как iframe с доменов Яндекса. Новые npm-зависимости не добавлены.

Проверка `npm test`: маршруты, статьи, canonical, внутренние ссылки и якоря, фотографии, редиректы и разрешение карты. Интеграционный тест PostgreSQL выполняется в GitHub Actions, где есть тестовая база; локально без DATABASE_URL он пропускается.

Production verification: the deployed Timeweb home page includes the new storefront, all store photos and the confirmed address. The embedded Yandex map loaded correctly on the published HTTPS site. Mobile visual verification remains unconfirmed because the browser viewport override was not applied.
