# QRONGE — сайт заявок для Mokwheel

Цены обновлены 2 октября 2026: каждая модель на 2 000 ₽ дешевле исходной таблицы.

Готовый проект: 12 моделей, 25 вариантов из таблицы, цены в рублях, акция до 1 ноября 2026 года, самовывоз. Платежей на сайте нет.

## Посмотреть локально

Нужен Node.js 24.14 или новее. Внешние npm-зависимости отсутствуют.

```bash
npm start
```

Откройте http://localhost:3000. Формы сохраняют заявки в `data/leads.sqlite`. В режиме разработки реквизиты могут быть пустыми. Для доступа к заявкам задайте `ADMIN_PASSWORD` и откройте `/admin/` (имя пользователя по умолчанию `manager`). Не открывайте режим разработки в интернет.

## Разместить в Яндекс Cloud

Проект предназначен для **виртуальной машины Yandex Compute Cloud** с Docker Compose. Сайт, API и база заявок работают вместе; фотографии локальные. Загрузка только HTML в Object Storage не запустит обработку заявок.

1. Создайте ВМ с Ubuntu, постоянным диском и публичным статическим IP. Начальный ориентир: 2 vCPU, 2 ГБ RAM, 20 ГБ диска; проверьте фактическую нагрузку после запуска. Разрешите входящие 80/443 и SSH только с административных IP. Порт 3000 не открывайте наружу.
2. Установите Docker Engine и Compose по официальной инструкции Docker для Ubuntu. Скопируйте папку проекта на ВМ, например в `/opt/qronge`.
3. Привяжите A-запись домена к IP ВМ. Скопируйте `.env.example` в `.env`, заполните настоящий `PUBLIC_ORIGIN` вида `https://shop.example.ru` **без завершающего слеша**, реквизиты продавца, адрес для обращений по данным. Сгенерируйте отдельный длинный пароль `ADMIN_PASSWORD` (минимум 20 символов), не используйте пароль от других сервисов. Ограничьте права файла: `chmod 600 .env`.
4. Запустите из папки проекта:

```bash
docker compose up -d --build
docker compose ps
```

5. Caddy получает HTTPS-сертификат и перенаправляет HTTP на HTTPS. Проверьте сайт и `/healthz` через домен. При ошибке смотрите `docker compose logs --tail=80 app caddy`.
6. Откройте `https://ваш-домен/admin/`, отправьте одну тестовую заявку, убедитесь, что она появилась. Проверьте с мобильного интернета в РФ без VPN: главную, фото, страницу модели, отправку заявки. Локальный тест не доказывает доступность из российских сетей.
7. Добавьте домен в Яндекс Вебмастер, отправьте `/sitemap.xml`. Укажите ID счётчика в `METRIKA_ID`, пересоздайте контейнер `docker compose up -d`, настройте цели из `docs/marketing.md`.

**Для публикации ещё нужны:** доступ к ВМ/Яндекс Cloud, домен и реквизиты продавца. Облачные ресурсы в рамках подготовки проекта не создавались. Окончательная публикация на Яндекс Cloud не выполнялась.

## Заявки и работа менеджера

- `/admin/` — защищённая таблица заявок, `/admin/leads.csv` — выгрузка для работы в таблице/CRM. Доступ закрыт HTTP Basic Auth поверх HTTPS.
- Уведомления в Telegram/email пока не подключены. При рекламе менеджер должен регулярно проверять раздел заявок. Для подключения уведомлений нужен выбранный канал и доступ к нему; не теряйте заявки, полагаясь на несуществующую отправку.
- Сохраняются модель, SKU цвета, количество, цена из каталога на момент заявки, отметка об индивидуальной цене, телефон, имя, дата, версия согласия, UTM и yclid. Цена определяется на сервере и не доверяет браузеру.
- Повторная отправка после обрыва сети с тем же идентификатором не создаёт дубликат. Успех показывается только после записи в базу. Антиспам: скрытое поле, проверка источника, лимит размера запроса, 10 новых заявок с одного адреса за час. Это базовая защита, не замена антибот-сервису при целевой атаке.
- База сохраняется в Docker volume `leads`. Пересборка контейнера её не удаляет. **Не используйте `docker compose down -v`: это удалит данные.**
- Заявки удаляются из рабочей базы через 90 дней. Для длительной работы с заказами своевременно переносите необходимые данные в свою систему.

## Резервная копия

```bash
docker compose exec -T app node backup.mjs
```

Согласованная копия SQLite сохраняется в отдельном volume `backups`; старые копии очищаются через 7 дней при следующем запуске команды. Настройте ежедневный запуск через cron и внешнюю защищённую копию/снимок диска: два volume на одной ВМ не защищают от потери ВМ. Для восстановления остановите приложение и восстановите проверенную копию в volume `leads`, исключив старые WAL/SHM. Перед восстановлением сохраните текущую базу.

## Редактирование

| Что изменить | Где |
| --- | --- |
| Цены, модели, цвета, доступность варианта, фото | `catalog.json` |
| Дата завершения акции, телефоны, самовывоз, порог партии | `config.mjs` |
| Тексты, страницы, SEO, политика | `render.mjs` |
| Цвета, отступы, мобильная версия | `public/style.css` |
| Форма и цели Метрики | `public/app.js` |
| Получение и хранение заявок | `server.mjs` |

После изменений пересоберите контейнер. Склад из таблицы не синхронизируется автоматически. На сайте намеренно нет точного счётчика остатков. Обновляйте `stock` у вариантов, чтобы недоступные SKU исчезали из выбора. Если модель полностью распродана, удалите её из каталога до следующего запуска рекламы.

## Особенности текущих данных

- Старые цены и процент скидки отсутствуют: зачёркнутые цены не выдумывались.
- Акция заканчивается **1 ноября в 00:00 по Москве**; после этого цены/Offer-разметка скрываются, заявка остаётся доступной с запросом актуальной стоимости. Новые цены не назначаются автоматически.
- **Оптовая цена — от 10 шт. одной модели.** Если в заказе две модели, минимальное количество для оптовой цены — 10 шт. каждой модели. Цена за одну штуку на 8 000 ₽ выше оптовой; порог и надбавка задаются в `config.mjs`.
- Заказ можно забрать самовывозом или отправить любой транспортной компанией за счёт покупателя. Отгрузка — после 100% оплаты заказа.
- Для M3+ и M3 Pro+ найдены только фото базовых M3 / M3 Pro. Для Spark — фото версии M; исполнение партии не подтверждено. Подписи на сайте объясняют это. До рекламы лучше заменить на фото именно вашей партии.
- У Zephyr SKU R1010047 конфликт цвета: русский столбец — красный, китайский — серебристо-серый. На сайте: «цвет уточняется».
- Контакты перенесены с вашего существующего сайта. Часы работы, гарантийные сроки, запас хода и мощность неподтверждённых версий не выдумывались.
- Публичные фото найдены в каталогах производителя и продавцов. Источники сохранены в `docs/photo-sources.json`. Наличие фото в интернете не подтверждает право коммерческого использования; предпочтительны согласованные фотографии поставщика или ваши собственные.

## Проверка

```bash
npm test
```

Тесты проверяют запись и повтор заявки, принадлежность цвета модели, телефон/согласие/количество, серверную цену, закрытый доступ к базе и админке, SEO-карту и границу завершения акции. Данные тестов временные.
