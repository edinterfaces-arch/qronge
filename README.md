# QRONGE — сайт заявок для Mokwheel

Каталог оптовых электровелосипедов с формой заявки и закрытым разделом менеджера. Цены в рублях, оптовый порог — от 10 штук одной модели, розничная цена за штуку выше оптовой на 8 000 ₽. Заказ можно забрать самовывозом или отправить транспортной компанией за счёт покупателя; отгрузка после 100% оплаты. Платежей на сайте нет.

## Деплой в Timeweb Cloud App Platform

В репозитории есть `Dockerfile` и `docker-compose.yml`. При создании приложения в App Platform выберите **Docker Compose**. Манифест содержит один сервис `app`, слушающий порт 3000. HTTPS и домен настраиваются в App Platform; Caddy и host-порты 80/443 не нужны.

### 1. Создайте PostgreSQL

Создайте PostgreSQL в Timeweb Cloud DBaaS отдельно от приложения и включите сетевой доступ из App Platform (через совместную приватную сеть, если она доступна, или разрешённый публичный доступ). Сохраните строку подключения и CA-сертификат базы. Приложение требует TLS с проверкой сертификата.

Заявки хранятся в этой PostgreSQL базе Timeweb. Обновление или пересоздание контейнера их не удалит. Локальная база в контейнере не используется. Включите резервное копирование базы в DBaaS и проверьте восстановление по правилам вашего проекта.

### 2. Создайте приложение

1. В Timeweb Cloud откройте App Platform и выберите репозиторий `edinterfaces-arch/qronge`, ветку `main`.
2. Выберите **Docker Compose** и файл `docker-compose.yml` в корне репозитория.
3. Добавьте переменные окружения приложения:

| Переменная | Значение |
| --- | --- |
| `PUBLIC_ORIGIN` | HTTPS-адрес сайта, без завершающего `/` |
| `ADMIN_USER` | Имя менеджера, например `manager` |
| `ADMIN_PASSWORD` | Уникальный случайный пароль длиной от 20 символов |
| `SELLER_NAME` | Наименование продавца для юридических страниц |
| `SELLER_INN` | ИНН продавца |
| `SELLER_ADDRESS` | Адрес продавца |
| `PRIVACY_EMAIL` | Email для обращений по персональным данным |
| `DATABASE_URL` | Строка подключения Timeweb PostgreSQL |
| `DATABASE_CA_CERT` | CA-сертификат PostgreSQL целиком, вместе с BEGIN/END CERTIFICATE |
| `METRIKA_ID` | Необязательно: ID счётчика Яндекс Метрики |

`DATABASE_CA_CERT` задайте как многострочную переменную. Сертификат не помещайте в Git. Не публикуйте `DATABASE_URL` и `ADMIN_PASSWORD`.

### 3. Подключите домен и проверьте заявки

Добавьте домен в настройках приложения App Platform, выполните DNS-инструкции Timeweb и дождитесь выпуска HTTPS-сертификата. Затем укажите итоговый HTTPS URL в `PUBLIC_ORIGIN` и перезапустите приложение, если требуется.

Проверьте главную страницу, `/healthz`, отправку тестовой заявки и защищённую страницу `/admin/`. Для экспорта используйте `/admin/leads.csv`. Доступ закрыт HTTP Basic Auth; не передавайте пароль менеджера по незащищённому соединению.

### Сетевой доступ к базе

Убедитесь, что App Platform может подключаться к адресу PostgreSQL. Если база разрешает только IP allowlist, настройте доступ по актуальным рекомендациям Timeweb для App Platform. Не открывайте PostgreSQL всему интернету без необходимости. Ошибка соединения или TLS не должна приводить к молчаливой потере заявки: сервер вернёт ошибку, а приложение сообщит об ошибке запуска, если база недоступна.

## Локальный запуск

Нужен Node.js 24.14 или новее и доступный PostgreSQL. Установите зависимости командой `npm ci`, скопируйте `.env.example` в `.env`, задайте `DATABASE_URL`, а затем запустите:

```bash
npm start
```

Откройте http://localhost:3000. PostgreSQL-схема создаётся при старте приложения. В production также обязательны публичный HTTPS URL, реквизиты продавца и пароль администратора не короче 20 символов.

## Заявки и работа менеджера

- `/admin/` — таблица заявок, `/admin/leads.csv` — CSV для таблицы или CRM.
- Уведомления в Telegram/email не подключены; менеджер должен проверять `/admin/`.
- Сохраняются модель, SKU цвета, количество, цена из каталога на момент заявки, отметка оптовой цены, телефон, имя, дата, версия согласия, UTM и yclid. Цена определяется сервером.
- Повторная отправка после сетевого сбоя с тем же идентификатором не создаёт дубль. Заявка считается принятой только после записи в PostgreSQL.
- Заявки старше 90 дней удаляются из рабочей таблицы. Перенесите необходимые данные в CRM до этого срока.
- Срок хранения данных базы и резервные копии зависят от настроек Timeweb DBaaS. Их нужно настроить и контролировать отдельно.

## Редактирование

| Что изменить | Где |
| --- | --- |
| Цены, модели, цвета, доступность варианта, фото | `catalog.json` |
| Дата завершения акции, телефоны, самовывоз, порог партии | `config.mjs` |
| Тексты, страницы, SEO, политика | `render.mjs` |
| Цвета, отступы, мобильная версия | `public/style.css` |
| Форма и цели Метрики | `public/app.js` |
| Приём и хранение заявок | `server.mjs` |
| Параметры контейнера и App Platform | `Dockerfile`, `docker-compose.yml` |

Склад не синхронизируется автоматически. Обновляйте доступность вариантов в `catalog.json`; точный счётчик остатков на сайте не показывается.

## Особенности каталога

- Цена за 1 штуку на 8 000 ₽ выше цены от 10 шт. одной модели. Для двух моделей оптовый порог считается отдельно: 10 шт. каждой.
- Заказ можно забрать самовывозом или отправить любой транспортной компанией за счёт покупателя. Отгрузка — после 100% оплаты.
- Для M3+ и M3 Pro+ найдены фото базовых версий M3 / M3 Pro. Для Spark — фото версии M; исполнение партии не подтверждено. Перед рекламой замените их на фото своей партии.
- У Zephyr SKU R1010047 есть конфликт цвета в исходных данных; на сайте указано «цвет уточняется».
- Часы работы, гарантийные сроки, запас хода и мощность неподтверждённых версий не выдумывались. Источники фото перечислены в `docs/photo-sources.json`; предпочтительны фотографии поставщика с подтверждённым правом использования.
- Акция заканчивается **1 ноября 2026 года в 00:00 по Москве**. После этого цены и Offer-разметка скрываются, новые цены автоматически не назначаются.

Подробности по аудитории рекламы собраны в `docs/marketing.md`. Деплой требует настройки App Platform, PostgreSQL, домена и переменных продавца в панели Timeweb; эти ресурсы не создаются автоматически самим репозиторием.
